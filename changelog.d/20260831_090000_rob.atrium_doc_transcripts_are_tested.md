### Fixed

- **The README's console transcripts show what the tool prints.** Three
  rendering changes in a row went by without touching them, so the `doctor`
  example still showed a header line that had been deleted, a `.` gutter glyph
  that is now reserved for readiness marks, no severity blocks and no code
  column; the `review` example still showed five bare keys on one line; and the
  clean-run example omitted the corroborator scope line, claiming a narrower
  check than `doctor` has ever made.

### Changed

- **Console transcripts in the docs are tested, like the YAML examples are.**
  The `doctor` transcript is now pinned to a real run of the graph it depicts,
  the `review` menu to what `_full_menu` prints, and any documented clean run
  has to name the scope `doctor` always names. "Docs are tested" covered what a
  command *accepts* and not what it *prints*, which is the half that drifted.
